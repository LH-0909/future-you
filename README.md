# 未来的你 青年健康数字实验室

一个可运行的中文 H5 / Web 健康科普程序。调整睡眠、运动、久坐和饮食习惯，在真实人体解剖参考模型上探索科普知识，再比较生活方式情景、制定并记录七日行动。

## 启动

需要 Node.js 20.19+ 或 22.12+，以及 pnpm。项目开发时使用 Node.js 24.19.0 / pnpm 11.25.0。

```powershell
cd E:\LH\future-you
pnpm install
pnpm dev
```

终端显示本地地址后，在浏览器打开。默认是 `http://127.0.0.1:5173/`。也可双击 `启动程序.cmd`，脚本会寻找当前电脑可用的 Node.js 和 pnpm。

```powershell
pnpm test
pnpm build
pnpm preview
```

构建产物位于 `dist`，可由普通静态服务器托管。模型和运行库都随构建输出提供，页面不依赖外部字体、模型 CDN 或接口密钥。

## 已实现

- 首屏「我的改变实验」完整主线：填写画像 → 冻结原始输入 → 只改变一个习惯 → 身体功能关联与前后提示 → 现在 / 7天 / 30天 / 1年双人体对比 → 将自己选定的目标写入七日计划。刷新保留原始画像、实验目标与阶段。
- 行动量时间图：睡眠机会、活动分钟、久坐小时使用显式公式累积；饮食只比较定性选择，不捏造血糖、营养摄入或生理指数。既有计划被替换前需明确确认。
- 真实解剖参考人体：1,050 个结构、14 个渲染批次，支持解剖透视、内脏、肌肉、骨骼、体表五种视图，旋转、缩放、器官热点与镜头聚焦。
- 画像输入：睡眠、每周中等强度活动、每日久坐、饮食场景、活动间歇；两个示例画像。
- 睡眠、运动、饮食、久坐四个实验室，修改共享画像，展示机制、解释和科学来源。
- 时间机器与平行人生使用「我的改变实验」同一份原始画像和用户选择，不再自动修改所有行为或只切换通用章节。
- 四题知识挑战，逐题解释与来源。
- 七日行动：启动时固定三项目标，本机保存、手动打卡、取消与补记；未到日期的打卡禁用。行动卡可导出 PNG；支持系统分享的设备可分享，否则下载。
- 科学依据、完整模型署名、清除本机数据、减少动画、真实模型截图的轻量模式。

## 技术与数据流

Vite + React + Three.js + CSS；图标使用 Lucide。三维渲染使用 Three.js 和 OrbitControls，没有同时维护第二套三维框架。

`画像输入 → normalizeProfile 参数校验 → evaluateProfile 科普情景 → 器官提示 / 模型热点 / 解释 → actionGoals 行动计划`。

时间机器与平行人生都调用 `scenarioAt`。时间节点不乘上任何生理变化系数，目标分支表达未来选择的习惯，避免将人为指数包装成健康分数或疾病概率。

画像、偏好和打卡通过 LocalStorage 保存，键为 `future-you:v1`。读取时校验版本、输入范围、目标结构、日期和打卡键；不可用时仍可体验，但不能跨会话保存。不采集姓名、病史、用药或身份信息。

## 模型来源与重建

BodyParts3D 4.0 经 Human Atlas 转换的模型 + Human Reference Atlas 男性肺参考 v1.4。数据均按 CC BY 4.0 署名使用；详细作者、原始链接、修改内容见 [模型署名](public/models/ATTRIBUTION.md)。应用中科学依据页面和三维视图也展示署名。

已内置准备好的模型，日常运行无需重建。需要重建时安装 Python / NumPy，并运行：

```powershell
python scripts/download-atlas.py 1c38bf35c254a891200d3cedecfd57abebe83d8d
python scripts/prepare-hra-lungs.py
node scripts/prepare-atlas.mjs
```

原始下载保存在忽略的 `.asset-source`。下载脚本记录 BodyParts3D 来源提交和 SHA-256；输出保留结构和本体标识。肺组织按支气管树对齐，是教学用组合模型，不是临床配准。模型压缩文件兼容静态服务器自动 gzip 解码与普通文件方式两种响应。

## 当前边界

程序为可交互的科普 MVP。模型是真实的参考解剖数据，用户输入没有测量任何器官状态。平台不提供诊断、治疗、个体风险预测或确定的医学生效时间。

当前使用成年男性参考体型，未提供女性体型或个体体型重建；知识题库和实验流程是精简版。没有后台账号、云端同步或可穿戴设备接入。触屏布局已做浏览器检查，实际手机 GPU、真实多点触控和所有屏幕阅读器仍需实体设备验证。

科学文案上线参赛前建议由医学科普审校人员复核。设计方案中的赛事页数认定、演示视频和正式作品开发文档需按赛事要求另行准备。
