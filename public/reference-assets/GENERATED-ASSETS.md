# Generated interaction assets

The six default pages are unmodified user-supplied originals. These three assets
are used only after selecting a different sitting posture on page 03.

All assets were generated with the built-in Image Gen tool, then inspected and
copied into this project. The reference/edit target was `posture-hero.webp`,
extracted from the user's third reference page. No CLI or external image API
was used. No generated asset replaces a default reference page.

| File | Dimensions | Use |
| --- | --- | --- |
| posture-standard-full.png | 1339 × 1175 | Upright standard sitting |
| posture-crossed-full.png | 1339 × 1174 | Crossed-knee sitting |
| posture-phone-full.png | 1339 × 1175 | Slouched smartphone sitting |

Shared prompt: Preserve the young Chinese man's identity, tousled dark hair,
gray hoodie, dark pants, bright blue-white study room, wooden desk, laptop,
office chair, left-facing side-view composition and photoreal rendering style.
Generate an individual 611:536 hero image at least 1024 pixels wide. Remove all
original labels, boxes, leader lines and UI. Preserve a translucent, coherent
spine, ribs and pelvis overlay aligned to the selected posture. No added text,
logos or watermark.

Standard posture: Change to natural upright sitting, head balanced over
shoulders, relaxed arms using the laptop, neutral spinal curves and upright
pelvis. Use pale teal-blue anatomy glow. Keep identity, furniture and lighting.
Feet are supported below the crop.

Crossed posture: Change to one knee clearly crossed over the opposite thigh,
with visible lower-leg/shoe context and mild pelvic asymmetry. Widen framing
enough to show the crossed legs. Preserve ivory/blue-white upper anatomy;
retain mild amber-red only around the pelvis and lowest lumbar vertebrae.

Phone posture: Change to slouched sitting with a phone naturally held in both
hands around lap or low desk height, downward gaze, rounded shoulders and
gently rounded lower back. Preserve an anatomy overlay following the pose,
with red-orange glow at the cervical and lumbar spine.
